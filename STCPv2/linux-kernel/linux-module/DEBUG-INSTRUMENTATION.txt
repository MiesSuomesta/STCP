STCPv2 crash-debug instrumentation

Added:
- stcp-debug socket state helper (sock/sk/ssk/sk_security/context/carrier/state/buffers/pid/comm)
- detailed stcp_release() lifecycle markers around sock->sk detachment, Rust/carrier xchg, orphan/release
- stcp_recvmsg() entry/exit/no-sk/no-context diagnostics
- child allocation state marker
- child->carrier initialized to NULL

Important: Linux LSM security_socket_recvmsg() runs before protocol ->recvmsg().
Therefore an AppArmor crash may happen without a recvmsg-enter marker.  In that
case the immediately preceding release-* markers are especially important.
