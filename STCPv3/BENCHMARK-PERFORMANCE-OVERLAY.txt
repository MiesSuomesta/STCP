STCP benchmark performance artifact overlay

Scope:
  tests/benchmark/benchctl.py only

Change:
  - report now writes <RUN_DIR>/performance.json from already validated case JSONs.
  - performance.json contains tx_mib_s, rx_mib_s and combined_mib_s for every case.
  - approve refuses publication approval if performance.json is missing.
  - No kernel/core/carrier/SDK/protocol implementation changes.

Apply from STCP tree root:
  unzip -o stcp-benchmark-performance-overlay-v6.zip

After a benchmark run:
  jq '.cases[] | select(.case_id | contains("throughput-stream")) |
      {case_id,tx_mib_s,rx_mib_s,combined_mib_s}' RUN_DIR/performance.json

NOTE:
  This overlay does not add tests/benchmark/run-all.sh to do-full-run.sh.
  It only makes the benchmark subsystem emit the machine-readable artifact
  required by the site-generator adapter.
