Enables CONFIG_SYS_HEAP_RUNTIME_STATS through STCP_RUST_CORE. Logs system k_malloc heap at socket-start (before context/carrier allocation) and alloc-failed. Fields: requested allocation size, used, free, peak. Peak is since heap initialization, not reset per benchmark. Retains existing STCP_MEM queue diagnostics. This reads actual system heap allocator statistics, not merely Rust requested-byte accounting. Internal _system_heap symbol and k_heap members are used for diagnostics; if your NCS fork changed them, provide compiler/link error. Snapshot synchronized with heap spinlock, logging happens after unlock.

Free bytes are total free memory, NOT largest contiguous free block. A failed allocation with free>N can indicate fragmentation/allocator search limitations, but does not prove corruption. No corruption validation added. Do not run this overlay as production logging. Rust/NCS toolchains unavailable here; target compilation and runtime verification required.
